# Linux Practice Lab – Day 21

## Lab Summary

In this lab, I learned several basic Linux commands used for system information, navigation, directory management, and file creation.

### Commands Learned

- `date` – Displays the current system date and time.
- `uptime` – Shows how long the system has been running, the number of logged-in users, and the system load average.
- `pwd` – Displays the current working directory.

### Absolute vs Relative Paths

I learned how to create directories using both Absolute and Relative Paths.

- **Absolute Path:** Specifies the complete path from the root directory. Example:
  ```bash
  /var/opt/images
  ```

- **Relative Path:** Specifies a path relative to the current working directory. Example:
  ```bash
  projects
  ```

Understanding the difference between these two path types is important for efficient filesystem navigation and management.

### File Creation

I practiced creating files using the `touch` command. I created a single file and multiple files using brace expansion, which made file creation faster and more efficient.

### Key Learning Outcomes

- Displayed the current date and time.
- Checked system uptime and load information.
- Identified my current location in the Linux filesystem.
- Created directories using Absolute and Relative Paths.
- Created files using the `touch` command.
- Learned basic Linux filesystem navigation and management.

### Most Useful Command

The command I found most useful was `pwd` because it quickly shows my current location in the filesystem.

### New Command Learned

The `uptime` command was new to me. I learned that it provides information about system uptime, logged-in users, and system load averages.

This lab improved my understanding of Linux command-line operations, filesystem navigation, directory creation, and file management. The hands-on exercises helped me become more comfortable working in a Linux environment.
